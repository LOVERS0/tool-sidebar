# ToolSidebar 1.10.0：常用工具更好找，安装更新更稳妥

把写作、AI 和系统工具收进一列，按 `⌥⌘T` 呼出，搜索后回车打开。这次更新主要改了列表、安装流程和翻译。

## 列表更好用

- 新增「全部 / 已安装 / 收藏」筛选，右键可收藏，收藏项排在各分类前面。
- 行右侧显示「打开、安装、更新、下载、访问、复制」，点之前就能看清操作。
- 搜索时复用已有列表行，减少重复创建视图；副标题更易读，开机自启和退出移入 `⋯` 菜单。
- 统一识别两个 Applications 目录中的应用，支持通过记录的 Bundle ID 查找移动、改名后的应用。

## 安装和更新

- 下载包按 Intel / Apple Silicon 匹配，优先选择 Universal；Rosetta 环境也会识别实际芯片。
- 新版先复制、校验，再替换旧版；替换失败时保留或恢复旧版。
- 自动安装要求签名及 macOS Gatekeeper 评估均通过，不再清除隔离标记。未通过会停止，并提供官方发布页。
- 应用自身统一通过 Sparkle 验证签名并更新；修复子进程输出阻塞和取消安装后的旧回调干扰。

## 翻译

- 在线翻译按段处理完整文本，不再只发送前 450 个字符。
- 编辑、再次提交、切换方向或关闭窗口会取消旧请求，避免旧结果覆盖新内容。
- 在线失败会明确标为词库替换；新增 `⌘↩`、输入提示和随窗口调整的布局。
- 默认离线模式仅做内置词语替换，不是全文翻译；MyMemory 在线翻译仍需手动开启。

## 下载与兼容

下载本页的 **ToolSidebar.zip**，解压后将 `小工具侧边栏.app` 放入 `/Applications` 或 `~/Applications`。

支持 **macOS 13+、Apple Silicon 和 Intel**。安装包为 ad-hoc 签名，尚未经过 Apple 公证；首次打开如被系统拦截，请先确认下载来源，再按「系统设置 → 隐私与安全」中的提示处理。自动更新包使用现有 Sparkle EdDSA 密钥签名。

本版通过本地回归检查和 Universal 编译；具体检查结果见仓库 CI。下载后可用同页的 `SHA256SUMS` 核对压缩包。
