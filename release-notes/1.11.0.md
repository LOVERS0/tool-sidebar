# ToolSidebar 1.11.0：专注应用启动与管理

这次更新做减法，保留日常找应用、开应用和管理应用需要的功能。

- 移除整个内置翻译，包括在线请求、离线词库窗口和对应菜单。
- 缺少明确来源的应用只显示「未安装」，不再按名字猜仓库并自动安装。
- 移除「安装全部推荐工具」。导入配置只恢复清单与设置，不再自动下载、安装一批应用；缺少的应用会显示为待安装项。
- 移除辅助功能设置入口和启动失败时的权限猜测，直接显示实际错误。
- 移除「去 AI 味」、网页排版、复制命令和 CLI 工具等非应用入口。

搜索、收藏、分类、快捷键、悬浮球、开机自启和配置备份继续保留。应用仍可逐个安装、更新和卸载。已有工具记录和旧版配置备份保持兼容；本次精简不会卸载你已经安装的软件。

下载 **ToolSidebar.zip**，解压后将 `小工具侧边栏.app` 放入 `/Applications` 或 `~/Applications`。现有用户也可以从应用的「检查更新…」升级。

支持 **macOS 13+、Apple Silicon 和 Intel**。安装包仍为 ad-hoc 签名，尚未经过 Apple 公证；自动更新包使用既有 Sparkle 密钥签名。本页提供 `SHA256SUMS` 供下载后核对。
